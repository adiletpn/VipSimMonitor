# VIP SIM Monitor

Асинхронный монитор красивых («блатных») номеров на витринах Tele2, Altel, Activ/Kcell и Beeline (Казахстан).
Каждый новый номер оценивается движком `scorer.py`, а улов прилетает карточкой в Telegram с кнопкой «⚡ ЗАБРАТЬ НОМЕР СЕЙЧАС».

Стек: `asyncio` + `aiohttp` + `aiosqlite`. Telegram Bot API вызывается напрямую (`tg.py`), без aiogram и pydantic. Поэтому процесс занимает около 40–60 МБ, а не 160.

## Структура

| Файл | Назначение |
|---|---|
| `main.py` | Точка входа: парсеры, очередь уведомлений, бот, обслуживание, graceful shutdown |
| `config.py` | Переменные окружения + динамические настройки из SQLite, импорт cURL |
| `scorer.py` | Оценка красоты номера: 4 группы правил, итог не больше 100 |
| `database.py` | SQLite в режиме WAL: дедупликация, уловы, статистика, настройки, автоочистка через 30 дней |
| `notifier.py` | Приоритетная очередь (сначала бесплатные), защита от флуд-лимитов, пауза 0,7 с |
| `bot.py` | Админ-панель (только для `ADMIN_CHAT_ID`) |
| `parsers/` | `base_parser.py` (анти-бан, Circuit Breaker, универсальный разбор JSON) и адаптеры операторов |

## Анти-бан

- Паузы между запросами к одному оператору: 20–35 с; в режиме `/turbo` — 10–15 с; с 01:00 до 05:00 по Астане — 45–60 с. Если турбо включён вручную, он важнее ночного режима.
- У каждого оператора своя сессия и свои cookies, а User-Agent не меняется до перезапуска. В запросах уходят полные браузерные заголовки: `Accept-Language: ru-RU,ru;q=0.9,kk;q=0.8`, `Origin`, `Referer` и `Sec-Fetch-*`.
- `refresh_session()` раз в 45 минут делает GET на главную страницу витрины.
- Circuit Breaker: при ответе 403/429 или после трёх сетевых ошибок подряд парсер этого оператора засыпает на 5–10 минут (учитывается `Retry-After`). Остальные операторы и бот продолжают работать.
- `PROXY_URL`: если задан, все запросы к операторам идут через этот прокси.
